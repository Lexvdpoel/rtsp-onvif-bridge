### The FFmpeg note

Debian builds FFmpeg with GPL-licensed encoders (libx264, libx265), which makes
the resulting binary GPL-2.0-or-later rather than LGPL. This project calls FFmpeg
as a separate process and does not link against it, but the binary is inside the
image. If you publish the built image, the GPL obligations for that binary come
with it. Building the image for yourself and running it does not raise the
question.

## Written from specification, not derived from code

The ONVIF device, media and events services and the WS-Discovery responder in
[app/camera/](app/camera/) were written against the published ONVIF
specifications and the SOAP, WS-Discovery and WS-Security standards. No ONVIF
reference code was copied.

ONVIF® is a trademark of the ONVIF consortium. This project is not affiliated
with, endorsed by, or certified by ONVIF, and calling a device here "ONVIF" is a
description of the protocol it speaks, not a claim of conformance testing.

## Acknowledgements

The certificate generation for UniFi adoption follows the OpenSSL invocation
documented by [unifi-cam-proxy](https://unifi-cam-proxy.com/), and the approach
of emulating a UniFi camera rather than settling for ONVIF generic mode is that
project's idea. The camera class this project registers is a subclass of theirs.

The two colours used for the throughput graphs come from a reference
data-visualisation palette chosen for colour-vision-deficiency separation. Colour
values are not copyrightable; the credit is for the reasoning, not the hex.
